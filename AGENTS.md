# AGENTS.md

This project is a test fixture. Keep it tiny.

- Run all checks with `./gradlew clean check`. It runs Checkstyle, the tests and JaCoCo.
- Run only the tests with `./gradlew test`.
- Public classes and methods need Javadoc (Checkstyle checks it).
- Do not add a dependency and do not change `build.gradle.kts` or the wrapper.
- Write a unit test for each new method. New code must be covered.
